# FunFan 1.0.0-alpha.1

第一个对外版本。**alpha** 的含义很具体：功能闭环了，但只在作者一台机器上跑过（Mac mini M4 / macOS 27），合盖与第三方共存这两条路还没在真机上走通。提前用的人请把「已知问题」看完。

FunFan 是个 macOS 菜单栏风扇控制工具：读 SMC 温度与电量，按规则或曲线自动调速，并在任何异常路径上把控制权还给系统。**只提速、不压转速**——任何策略的结果都不会低于按温度算出的安全下限，也绝不写 0 RPM。

## ⚠️ 这个包没有签名证书

项目没有购买 Apple Developer Program（$99/年），产物是 adhoc 签名、未公证。macOS 会拦一次，按下面第 3–4 步放行即可。介意的话从源码构建——自己编出来的包没有这道拦截。

## 安装

1. 下载 `FunFan-1.0.0-alpha.1.dmg`，双击打开
2. 把 FunFan 拖进「应用程序」，然后**卸载镜像**。别在 DMG 里直接运行——从挂载的镜像启动会走 App Translocation（随机只读路径），报的是「已损坏，无法打开」，后台组件也会装不上
3. 双击 FunFan：macOS 拦一次「Apple 无法验证」
4. 点**完成**（不要点「移到废纸篓」）→ **系统设置 → 隐私与安全性 → 安全性 → 仍要打开** → Touch ID 或密码确认

菜单栏出现风扇图标就算装好了，没有 Dock 图标、不占 ⌘Tab。

控制风扇需要再授权一次后台组件：点开面板 → 底部「一键启用」→ 输入一次系统密码。之后升级 App 不用再授权。

放行一次长期有效，**但每次升级都要重复第 3–4 步**，因为重新下载会重新带上隔离属性。

两个容易卡住的点：那个「仍要打开」按钮只在尝试打开后约 **1 小时**内出现，找不到就重新双击一次 App 让它再被拦；**右键 → 打开**这条老捷径从 macOS 15 起已被 Apple 移除，按了没用。

## 这个版本有什么

- **温度监控**：全键枚举 SMC 传感器（作者机器 180 个），按 CPU / GPU / 内存 / SSD / 电池 / 环境归类，CPU 与 GPU 同时给均温和逐核明细
- **电量监控**：走 `IOPMPowerSource`，台式机正确显示「无电池」
- **四种策略**：自动（交还系统）/ 固定转速 / 曲线（多控制点，斜率限制防突跳）/ 规则（`CPU 均温 ≥ 60℃ → 3500 RPM` 这类，40 RPM 死区防抖）
- **安全下限**：按温度线性给出下限，60℃ 对应最低、95℃ 对应满转；任何策略都不能低于它，多规则冲突取最大值
- **租约看门狗**：GUI 崩溃、被杀、退出、睡眠、合盖，风扇都会在约 10 秒内回到系统控制
- **第三方接管检测**：发现已经有人在写风扇就不抢，提示里说清是谁
- **一键诊断**：机型、芯片、系统、SMC 键数、温度键可读率与不可读清单、风扇区间、后台组件状态与日志尾，一键复制成 Markdown

## 已知问题（alpha 就该说清楚）

- **一次性授权那条路没验成**：`SMAppService` 系统登记在 adhoc 签名下「注册得上但启动不了」，所以实际走的是管理员授权直装（`/Library/PrivilegedHelperTools/com.funfan.helper`）。效果一样，代价是要输一次密码，且每次重装 App 都要重装组件。有 Developer ID 证书之后才能验正式那条路
- **合盖行为未在真机验证**：开发机是 Mac mini，没有盖子。代码里「合盖 → 交还系统 → 挂起期间拒绝重新接管 → 开盖恢复」这条链只用 `--simulate-lid` 注入验过（实测开盖后 0.3 s 恢复接管）
- **没和 Macs Fan Control 真机共存过**：冲突检测的判据（`F0Md=1` 且我们没有租约）有单测覆盖，但没拿真软件对撞
- **只支持 Apple Silicon + macOS 13+**：读 SMC 的路径是按 Apple Silicon 写的，Intel 机器不保证能用
- **公证/签名链路未验**：脚本齐全但没证书可跑，所以 `make notary-check` 只能验失败路径

## 变更

首个版本，没有「上个版本」可比，所以这里是到目前为止的里程碑：

- M1–M2：SMC 访问层（80 字节结构体、类型编解码、含 `ioft` 定点数）、传感器目录与采样
- M3：控制层（安全下限、死区、租约看门狗）与规则引擎
- M4：特权后台组件（XPC + 看门狗 + 退出即返还）
- M5：菜单栏 GUI、规则编辑器、设置窗口
- 曲线策略与曲线编辑器（含真机端到端验证：目标 2116→2333 单调跟随，实际误差 0–3 RPM）
- 后台组件一键安装、Popover 交互修复、可访问性焦点环按控件形状重绘
- 打包与发布链路：`.app`、签名/公证脚本、DMG、单测 281 个

## 系统要求

macOS 13 Ventura 或更高，Apple Silicon（M1 及以上）。

## 反馈

报问题时请附上诊断报告：App 菜单栏面板里点「诊断」（会复制到剪贴板），或者源码目录跑 `make diagnose`。里面有温度键可读率、风扇区间、后台组件状态和日志尾——比「不工作」三个字有用得多。
