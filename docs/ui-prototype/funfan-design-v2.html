关于

免责声明

本工具通过 AppleSMC 直接写入风扇目标转速。所有写入都会先收敛到系统区间与动态安全下限，且绝不发送 0 RPM；但底层接口未公开，系统升级后可能失效。请自行承担使用风险。

FunFan 不收集任何数据；诊断报告只在你点击「复制」时生成，保存在本机。

  • 数值永远是 text-1，状态只由指示物承担 —— 解决「一切正常=全绿」导致颜色无信息、且压低数值层级的问题。
  • 状态不只靠颜色：正常=实心点，偏高=点+外环，过热=三角。色觉障碍下仍可分。
  • 温度色不再出现在按钮和提示条；提示条只用 attention / error，两套标尺不混。

卡片与层次

  • 深色：卡片 #2a2a2e + rgba(255,255,255,.08) 描边（v1 只有 5% 填充差，1.19:1）。
  • 浅色：白卡 + rgba(0,0,0,.07) 描边 —— 边界由描边承担，不再依赖填充差（v1 浅色卡片与底只差 1.10:1，视觉上会「飘」）。
  • 设置分组不再用「10pt tertiary + uppercase」当标题，按钮统一为自绘 6pt 圆角，和 Popover 同源。
  • 禁用态：整组降饱和 + 保留文案可读，不用 0.45 alpha 把字压到 1.5:1。

外观切换（要求 1 的落地）

  • 跟随系统：三态之一，默认值。系统明暗变化时即时生效，本稿已实现（改系统外观会自动跟随）。
  • 手动覆盖：只作用于 FunFan 自己的窗口与 Popover，不改系统设置，也不动菜单栏图标（避免浅色菜单栏配深色文字）。
  • 切换时机：改设置后已打开的窗口立即跟随，不需重开；Popover 打开状态下切换不闪、不改变高度。
  • 实现侧建议：调色板由 colorScheme 环境解析（Palette.dark / .light），不要用 Assets 色彩集或 NSColor 动态色 —— 那两条走 NSAppearance.current，会让离屏走查再次看不到浅色。
  • 离开工具链：--render ... --scheme light 应成为设计走查的必备开关。
