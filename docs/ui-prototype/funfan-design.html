关于 / 免责
FunFan 通过用户态 IOKit 读取传感器、经特权 helper 调节风扇转速，全程不绕过 macOS 自身热保护。 调速仅「提高」系统默认转速，不会将风扇压至系统安全下限以下。使用本软件的风险由用户自行承担； 如与其他风扇控制软件并存，FunFan 检测到冲突将拒绝接管。

设计稿说明：本原型用于评审视觉与信息架构，配色/间距已抽象为 Design Tokens（见落地指南）， 最终实现为 SwiftUI（macOS 13+），菜单栏 Popover 宽约 320pt，设置/规则为独立窗口。 深色为默认主题，亮色主题沿用同套令牌。
